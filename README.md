# 外苑いちょう並木　最後の一葉

明治神宮外苑のいちょう並木を 3D で再現したブラウザゲームです（Three.js）。

青山通りから聖徳記念絵画館へと続く 146 本のイチョウ並木。黄金色の葉は見頃を迎えていますが、
木枯らしのたびにどんどん散っていきます。イチョウのてっぺんに触れると、その木の紅葉がよみがえります。

## ルール

- **イチョウのてっぺんに触れる**と、その木の葉がよみがえる
- **すべての木が葉を落としきったらゲームオーバー**
- **車道を走る車（外車が多い）にぶつかってもゲームオーバー**
- 1分で1日が過ぎる。夜はライトアップ。深夜〜早朝は人通りが少ない
- 並木の葉が多いほど、遊歩道を歩く人が増える
- 舞い落ちる葉をクリックでつかむとスコア。金の葉は 10 枚分

## 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | W A S D / 矢印（Shift で走る） | 左下のスティック |
| 見回す | マウス | 画面右側をドラッグ |
| ジャンプ | Space 長押しでためて離す（長いほど高く、MAX で木の上まで） | 「ジャンプ」ボタン長押し |
| 木登り | 幹に向かって W（S で降りる） | スティックを前に |
| 葉をつかむ | クリック | 画面をタップ |

木の上や車の屋根には乗ることができ、そこからジャンプもできます。

## 描画の仕組み

- **樹形**：3種類（細身の尖塔型・標準の円錐・段のある円錐）。色づきは木ごとに「緑が残る／鮮やかな黄色／茶色く枯れ始め」を割り当て
- **LOD**：15m以内は個々の小さな葉を追加、40mまでは葉の房、100mまでは房を間引いて拡大、それ以遠は円錐の樹冠だけ
- **シェーダー**：頂点シェーダーで木全体の揺れと葉の細かな揺れ（突風で強まる）、逆光で葉が金色に透ける簡易SSS
- **テクスチャ**：葉は1KのAlbedo＋Normal（CanvasでProcedural生成）、幹は2KのAlbedo / Normal / Roughness（縦方向リピート）
- **インスタンシング**：幹・枝・葉・樹冠はすべてInstancedMeshで描画。当たり判定は幹のみ

## 遊び方 / 公開

`main` に push すると GitHub Actions（`.github/workflows/pages.yml`）で GitHub Pages に公開されます。

ローカルで遊ぶ場合:

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。動作が重い場合は `?q=low` を付けると軽量モード（影なし）になります。
