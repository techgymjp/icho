# 外苑いちょう並木　最後の一葉

明治神宮外苑のいちょう並木を 3D で再現したブラウザゲームです（Three.js）。

青山通りから聖徳記念絵画館へと続く 146 本のイチョウ並木。黄金色の葉は見頃を迎えていますが、
木枯らしのたびにどんどん散っていきます。7日間でイチョウの葉をどれだけ残せるか？

## ルール

- いちょう祭りの **7日間（1日＝1分）** を、最後の一葉を散らせずに守り切ればクリア
- スコアは **7日目の終わりに葉が残っていた木の本数**（あわせて、残った葉の量も表示）
- 葉が75%を切って枯れかけた木には **光る玉** が出る（根元・てっぺん・幹の途中のどこか）。触れるとその木がよみがえる
- 同じ木をよみがえらせられるのは **2日に1回まで**（よみがえらせられない間は玉が光らない）
- **すべての木が葉を落としきったら** ゲームオーバー
- **車道を走る車（外車が多い）にぶつかっても** ゲームオーバー
- 夜はライトアップ。深夜〜早朝は人通りが少なく、並木の葉が多いほど遊歩道を歩く人が増える
- 舞い落ちる葉をつかむとボーナス。金の葉は 10 枚分

## 操作

遊び方の詳細はゲーム内の「遊び方」ページ（`howto.html`）にあります。

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | W A S D / 矢印キー（押し続けるほど速くなる。Shift で走る） | 左下のスティック |
| カメラ | プレイヤーの約8m後ろからの三人称視点。マウスで回す | 画面右側をドラッグ |
| ジャンプ | Space を押した瞬間に跳ぶ。押し続けるほど高く上がり、最大で木のてっぺんへ | 「ジャンプ」ボタン |
| 木登り | 幹に向かって進む | スティックを幹の方へ |
| 葉をつかむ | クリック（そばを舞う葉をつかむ） | スティック以外の場所をタップ |

木の上や車の屋根には乗ることができ、そこからジャンプもできます。柵は越えて車道にも出られます。

## 描画の仕組み

- **葉と枝**：葉は枝に沿って付き、枝の先ほど茂る。近くの木は樹冠の芯を細くして枝と葉が見えるように
- **樹形**：3種類（細身の尖塔型・標準の円錐・段のある円錐）。色づきは木ごとに「緑が残る／鮮やかな黄色／茶色く枯れ始め」を割り当て
- **樹木テンプレート**：樹形3種 × 葉の量5段階（100/75/50/30/10%）。枝と小枝に、扇形の葉が数枚ずつ付いた房を約7000個付ける。各木は葉の量に合った段階を表示
- **LOD**：70mより遠い木は房を間引いて大きくしたテンプレート
- **シェーダー**：頂点シェーダーで木全体の揺れと葉の細かな揺れ（突風で強まる）、逆光で葉が金色に透ける簡易SSS
- **テクスチャ**：葉は1KのAlbedo＋Normal（CanvasでProcedural生成）、幹は2KのAlbedo / Normal / Roughness（縦方向リピート）
- **インスタンシング**：幹・枝・葉・樹冠はすべてInstancedMeshで描画。当たり判定は幹のみ

## 遊び方 / 公開

`main` に push すると GitHub Actions（`.github/workflows/pages.yml`）で GitHub Pages に公開されます。

ローカルで遊ぶ場合:

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。

画面左下に fps と画質（高画質・標準・軽量）を表示します。30fps を3秒続けて下回ると、自動で画質を1段下げます。

葉の散る速さは木ごとにばらばらで、時間とともにゆらぎ、ときどき一気に散ります。動作が重い場合は `?q=low` を付けると軽量モード（影なし）になります。
